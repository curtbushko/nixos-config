# Go Review Knowledge Compatibility Entry

For a dispatched implementation review, follow `go-code-reviewer` and its
`mtn-tasks` handoff. Do not issue a second review from this compatibility name.

For standalone Go questions, consult [mistake patterns](knowledge-base.md) and
[production patterns](real-world-patterns.md) as needed. Give evidence-based
findings; do not imply a workflow APPROVED verdict without the exact task,
revision and required independent checks.
