# Zig Architecture Review Compatibility

Follow `architecture-reviewer`, `zig` and the `mtn-tasks` review contract.
Use the triggered `architecture` scope from the approved review plan.
Do not impose a fixed layout or block unrelated historical debt automatically.

Set `user_decision_required: true` for material unresolved risks/scope conflicts;
provide evidence, impact and options. Run relevant repository-wide automated architecture gates
when required by the actual project and budget, not as a universal tool mandate.
Keep the existing run identity; do not spawn a replacement reviewer.
